# Project PitWall 

A Python-based motorsport telemetry analysis and driver comparison project.

## Current Version

v1.1 — Driver Comparison

## What it does

- Reads telemetry data from CSV files
- Analyzes speed, braking, acceleration and lateral G
- Compares two drivers turn-by-turn
- Calculates time differences between drivers
- Visualizes time gained and lost at each turn

## Technologies

- Python
- Pandas
- Matplotlib
- Git
